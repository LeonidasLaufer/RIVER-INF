# RIVER-INF

![Linguagem](https://img.shields.io/badge/Language-C-blue)

> Remake do jogo River Raid de Atari em C.
---

## Ferramentas
* **Linguagem:** C
* **Biblioteca Gráfica:** [raylib](https://www.raylib.com/)
* **IDE:** Visual Studio 2022
* **Versionamento:** Git

## Funcionalidades
* **Movimentação Horizontal livre e velocidade contante para cima**
* **Mecânica de combustivel e reabastecimento**
* **Mapa e inimigos determinados por arquivo-texto**
* **Game States:** Menu, jogo, morte

## Como rodar

1. Clone o repositório: Utilize **Clone Repository** no Visual Studio e cole: https://github.com/LeonidasLaufer/RIVER-INF
2. Abra o arquivo sln
3. Configure o raylib no diretório do projeto
4. Compile e rode pressioando F5
